数据脱敏、对话压缩、动态提示、多瓶体适配。
# LLM Smart Proxy — 一句话说明

**它是一个"中间人"，站在你的 AI 工具和云端模型之间，默默帮你省钱、保密、提速。**

---

## 它能帮你做什么？

### 💰 省钱（减少 Token 消耗）

正常使用 AI 时，每次提问都会把全部上下文（之前的对话、系统提示等）打包发给云端。上下文越长，花的钱越多。

Proxy 的做法：如果是个简单问题（比如"今天天气怎么样"），直接跳过压缩原样发送。如果是复杂追问，它会先让模型自己做个摘要，然后用摘要 + 你的问题去问模型。

**效果：长对话的场景，Token 消耗减少 30%-50%。**

### 🔒 保密（数据脱敏）

你用 AI 处理工作文件（投标书、合同、用户数据），里面的电话号码、公司名、金额等信息会直接上传到云端服务器。

Proxy 的做法：在数据发出去之前，自动把敏感信息替换成占位符（手机号 → [手机1]，公司名 → [公司1]）。云端模型看到的是脱敏后的版本。返回结果后，你可以对照本地日志还原。

**效果：敏感数据不离开你的电脑。**

### 📎 文件守护

如果你不小心把包含公司信息的 PDF 或截图丢给了 AI，Proxy 会检测到并提醒你：这段请求里包含无法脱敏的文件附件。

**效果：防止敏感文件裸传云端。**

### ⚡ 提速（智能路由）

Proxy 判断你的问题是"独立问题"还是"追问"。独立问题直接透传，省掉摘要环节的 2-3 秒。

**效果：闲聊类请求秒回。**

## 怎么用？（3 步）

### 第 1 步：启动 Proxy

打开终端（Mac 叫"终端"，Windows 叫"命令提示符"或 PowerShell），输入：

```bash
cd ~/.workbuddy/scripts
python3 proxy.py
```

看到这样就算成功了（端口号可能是 4001，如果被占用会自动切换到 4002/4003 等）：

```
============================================================
  LLM Smart Proxy v10.1
  监听: http://0.0.0.0:4001    ← 如果被占用会显示 4002/4003...
============================================================
```

**让终端保持开着就行，不要关。**
> **自动端口检测**：如果端口被其他程序占用了，Proxy 会自动换一个端口，不用担心冲突。

### 第 2 步：配置你的 AI 工具

把你平时用的 AI 工具的"服务器地址"改成启动日志里显示的实际端口：

`http://127.0.0.1:实际端口号/v1/chat/completions`

| 你用的工具 | 在哪里改 |
|-----------|---------|
| **WorkBuddy** | models.json 里 url 改成 `http://localhost:实际端口/v1/chat/completions` |
| **OpenClaw** | 环境变量 `OPENAI_BASE_URL` 或自定义 Provider |
| **VS Code + Cline** | Cline 设置 → Base URL 填 `http://localhost:实际端口/v1/chat/completions` |
| **Codex CLI** | 环境变量 `CODEX_API_BASE_URL=http://localhost:实际端口/v1` |
| **Hermes** | 模型配置里改 url |
| **所有 OpenAI 兼容工具** | 任何支持 OpenAI API 格式的客户端都能接 |

### 第 3 步：正常使用

改完地址后，照常使用你的 AI 工具就行。Proxy 在后台自动工作，你感觉不到它的存在。

## 什么时候需要操心？

### 开启/关闭脱敏（在聊天里直接说就行）

**不需要改配置文件**。在任何 AI 工具聊天框里发送以下指令即可：

```
/sanitize on        ←  开启脱敏（自动替换敏感信息）
/sanitize off       ←  关闭脱敏
/sanitize detect    ←  仅检测，不替换（先看看有哪些敏感信息）
/sanitize status    ←  查看当前脱敏状态
```

中文也支持：`开启脱敏`、`关闭脱敏`、`脱敏状态`

Proxy 会立即回复确认消息，不会消耗 AI 的 token。

### 处理敏感文件前

在终端运行：

```bash
cd ~/.workbuddy/scripts
python sanitize.py --preflight 你的文件夹路径
```

它会扫描文件夹，告诉你里面有没有敏感信息。确认没问题再开始工作。

### 想看看省了多少 Token

浏览器打开：`http://127.0.0.1:实际端口/stats`

### Proxy 挂了怎么办？

如果 Proxy 意外关闭，你的 AI 工具会提示连接失败。重新启动 Proxy 即可（重新执行第 1 步）。

## 常见问题

| 问 | 答 |
|----|-----|
| 需要一直开着吗？ | 是的。可以设为开机自启，就不用手动开了。 |
| 会影响 AI 的回答质量吗？ | 不会。Proxy 只是帮你整理请求，不影响模型能力。 |
| 会不会偷偷记录我的数据？ | 不会。Proxy 运行在你本地电脑，所有数据不离开你的机器。 |
| 对电脑有要求吗？ | 几乎没要求。只需要 Python 3.10+，任何近年电脑都能跑。 |
| 我不用 WorkBuddy 能用吗？ | 可以。任何支持 OpenAI API 格式的 AI 工具都能接。 |
| 怎么临时开关脱敏？ | 在聊天框发 `/sanitize on` 或 `/sanitize off`，即时生效。 |
